# Daily Wins Tracker - User Stories

This document contains all user stories for the Daily Wins Tracker application, organized by Epic.

## 📖 User Stories

### Epic 1: User Authentication

- As a new user, I want to register an account so that I can start tracking my daily wins
- As a returning user, I want to log in securely so that I can access my personal entries
- As a user, I want to log out so that my data remains private on shared devices

### Epic 2: Daily Entry Management

- As a user, I want to record my daily wins so that I can celebrate my achievements
- As a user, I want to track my mood so that I can identify emotional patterns
- As a user, I want to write gratitude notes so that I can maintain a positive mindset
- As a user, I want to edit past entries so that I can correct mistakes or add details
- As a user, I want to delete entries so that I can remove personal information if needed
- As a logged-in user, I want to create a daily entry so that I can record my wins and gratitude
- As a user, I want to view my entries in a weekly calendar so that I can see my progress at a glance

### Epic 3: Organisation & Categories

- As a user, I want to create custom categories so that I can organize my wins by theme
- As a user, I want to assign multiple categories to entries so that I can track overlapping areas
- As a user, I want to filter entries by category so that I can review specific areas of my life

### Epic 4: Quick Capture & Sticky Notes

- As a user, I want to quickly jot down thoughts so that I don't forget fleeting ideas
- As a user, I want to convert sticky notes to wins so that I can track completed tasks
- As a user, I want to see my sticky notes on every page so that I remember important reminders
- As a user, I want to use sticky notes so that I can capture quick thoughts

### Epic 5: Search & Discovery

- As a user, I want to search my entries so that I can find specific wins or reflections
- As a user, I want to browse all my entries so that I can review my journey
- As a user, I want to see entry previews so that I can quickly scan content
- As a user, I want to search my entries so that I can find specific content

## User Stories with Acceptance Criteria (from TESTING.md)

### Authentication Stories

**As a new user, I want to register for an account so that I can save my daily entries**

Acceptance Criteria:
- Registration form accessible
- Email validation works
- Password requirements enforced
- Account created successfully

**As a returning user, I want to log in to my account so that I can access my previous entries**

Acceptance Criteria:
- Login form accessible
- Credentials validated
- Redirected to dashboard
- Previous data visible

### Entry Management Stories

**As a logged-in user, I want to create a daily entry so that I can record my wins and gratitude**

Acceptance Criteria:
- Entry form accessible from dashboard
- Three-part structure visible
- Can save partial entries
- Success message shown

**As a user, I want to view my entries in a weekly calendar so that I can see my progress at a glance**

Acceptance Criteria:
- Dashboard shows current week
- Can navigate between weeks
- Day cards show entry previews
- Empty days clearly marked

**As a user, I want to edit my entries so that I can update or correct information**

Acceptance Criteria:
- Can reopen existing entries
- Form pre-populated with data
- Changes save correctly
- Success message shown

**As a user, I want to delete entries so that I can remove unwanted content**

Acceptance Criteria:
- Delete button available in modal
- Confirmation required
- Entry removed from system
- Success message shown

### Category Management Stories

**As a user, I want to create custom categories so that I can organize my entries**

Acceptance Criteria:
- Category creation form accessible
- Can choose from 8 colors
- Categories saved per user
- Success message shown

### Sticky Notes Stories

**As a user, I want to use sticky notes so that I can capture quick thoughts**

Acceptance Criteria:
- Can create up to 6 notes
- Notes editable inline
- Can mark as complete
- Can convert to entry

### Search & Discovery Stories

**As a user, I want to search my entries so that I can find specific content**

Acceptance Criteria:
- Search form accessible
- Searches all entry fields
- Results displayed clearly
- No results message shown
